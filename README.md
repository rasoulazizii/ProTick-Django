# ProTick - Advanced Ticketing System

ProTick is a scalable backend solution for event management and ticket sales. 
Built with a focus on high concurrency and data integrity.

## Tech Stack
- **Framework:** Django, Django REST Framework
- **Database:** PostgreSQL
- **Task Queue:** Celery & Redis
- **Containerization:** Docker & Docker Compose

## Current Progress (Phase 1)
- [x] Custom User Model (Email Authentication)
- [x] Core Models (Event, Organizer, TicketType)
- [x] Docker Infrastructure setup
